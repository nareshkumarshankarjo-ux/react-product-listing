# Product Listing Using React JS

This project is a dynamic Product Listing Application created using React JS.

It demonstrates React components, props, state management, event handling, list rendering, search, filtering, sorting and shopping cart functionality.

## Features

- Display products in responsive grid layout
- Search products by name
- Real-time search functionality
- Filter products by category
- Sort products by price
- Sort products by name
- Reset search and filters
- Add products to cart
- Update cart item quantity
- Display cart item count
- View shopping cart
- Calculate total cart price
- Remove items from cart
- Responsive mobile layout
- No products found message
